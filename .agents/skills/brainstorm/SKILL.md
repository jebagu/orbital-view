# Brainstorm Skill

## Purpose

Turn a fuzzy idea into a clear product direction.

## Use When

- The feature is not fully shaped
- There are multiple possible approaches
- The UI or interaction is unclear
- Jeremy wants tradeoffs before implementation

## Do Not Use When

- The task is already clear
- There is already an approved OpenSpec proposal
- This is a tiny bug or copy change

## Process

1. Restate the idea plainly.
2. Identify what user problem it solves.
3. Offer 2 to 3 possible approaches.
4. For each approach, explain tradeoffs.
5. Recommend the smallest useful version.
6. Identify what is out of scope.
7. End with a short summary for Architect.

## Output

Return:

```text
Product direction:
Recommended approach:
Smallest useful version:
Out of scope:
Open questions:
Should we create a visual mockup:
Should we create an OpenSpec proposal:
```
