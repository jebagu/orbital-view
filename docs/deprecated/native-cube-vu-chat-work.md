## Scope

All implementation work produced in the chat that introduced or extended the native Cube VU merge is deprecated and must not be treated as the desired implementation direction.

This includes:

- the native Cube VU renderer merge from Orbital View VU Kit
- browser-derived Cube VU settings and diagnostics added during that merge
- dynamic object overlay contracts added as part of that merge
- the `OrbitalViewViewer` executable target
- the `OrbitalViewViewerSupport` demo-data target
- the viewer demo tests
- docs that describe the above as the active/current direction

## Instruction For Restart

Do not build on this work when starting the next implementation pass. Treat it as abandoned exploration unless the user explicitly asks to salvage a specific file, API, test, or visual idea.

The current repository may still contain the deprecated files and diffs until a cleanup/revert pass is explicitly requested.
