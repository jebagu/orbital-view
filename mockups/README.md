# Mockups

This folder contains disposable HTML/CSS/JS mockups.

Use these when Jeremy wants to see the UI or interaction before Swift implementation.

Rules:

- No Swift.
- No production architecture.
- Fake data is fine.
- Fake audio processing is fine.
- Show states and flow.
- Keep it fast.
- Do not let mockup code become production scaffolding.

Each mockup should have:

```text
mockups/[feature-name]/index.html
mockups/[feature-name]/notes.md
```
